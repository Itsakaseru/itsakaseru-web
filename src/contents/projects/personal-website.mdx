# Starting Point
Hmm... where should I even start?

This project is basically the thing you are looking at right now. This website. My personal website. It has gone through many generations over the years, from the time when I didn’t even really know how to code, until now, where I have slowly learned more things about web development.

Technically, there was a very, very first version before all of this. I would probably call it v0. Unfortunately, I can’t seem to find where I put the files for it. Maybe it still exists somewhere, hiding in an old folder, waiting to be discovered again. If I ever find it in the future, perhaps I’ll add it here.

# Ini the beninging - Version 1.0
But for now, let’s begin with v1, **11 November 2019**

v1 started when I made this website as one of my college assignment projects. At the time, I was still learning the basics, so the website was built using pure HTML, Bootstrap, and a few other libraries like jQuery. It was simple. Plain simple. The homepage mostly had some links, contact information, and a logo positioned in the center. That was pretty much it. But even though it was basic, this version was important to me because it marked the beginning of me learning how to properly design and style things.

I started playing osu! a lot in High school. Because of osu!, I became inspired by the design of ppy’s website, which influenced how I wanted my own website to feel. osu! also became one of the reasons I started getting more interested in anime and Japanese-related things. Looking back, it was pretty obvious from the avatar image I used back then. It came from one of the first Pixiv artists I discovered, and I really liked the art style. I adjusted it a little bit, edited the hair, and used it as my proper avatar image, so umm.. Thank you very much, fishy! and sorry!

# The first leaf - Version 1.5
Then, on **January 8, 2021**, version 1.5 started being worked on.

At this point, things started to settle a little bit. I began exploring more proper design and styling, slowly finding my own style, applying it to the website, and there we go~

That was basically it, actually. I went with a card-based design, which was something I really liked at the time. It made the website pop more, and honestly, I liked it compared to the previous one.

Around this time, I also started thinking that my personal website could actually become something useful in the future. Not just as a random page on the internet, but as a place where I could apply the things I had learned or even use it as a way to learn more about web development. For me, there is something really satisfying about learning something and then being able to see the result of it directly. It makes the learning process feel more real, like, “Oh, so this is what I can make now.”

Because of that, many ideas started coming to mind. Maybe I could expand from the base concept and start adding more pages, such as a portfolio page or an about me page. A place where I could showcase the things I had done in the past, or at the time, and well... introduce myself properly on the internet.

Although, as the version name says, this was still v1.5, so it was very much still being worked on. Portfolio and about me page? Coming soon! And don't ask about responsive design yet.

# It starts becoming clear - Version 2.0
Then came v2.0, which started being worked on around **July 20, 2021**.

This version was built around the time when I started learning React.js, while also jumping into Next.js, which was starting to get more popular. At the same time, I was also learning TypeScript, so yeah... a lot of things were happening at once.

At this point, I started to get the hang of design and styling a little bit more. I tweaked the design from the previous version, such as removing the overpowered shadows, using a more proper colour palette, choosing better fonts, and making the overall website looks much more better. Oh, and it was also responsive now! Finally.

This version also introduced a new about me page and a portfolio list page, including portfolio detail pages. For the portfolio detail page, I designed it kind of like an “app store” page at the time, where each project had its own details, images, and presentation. The colour of the page would also adjust based on the portfolio’s colour theme, which honestly felt really cool to me.

Oh, and it also had a carousel. Or gallery. Either way, there were images you could slide through, and that already made it feel way more alive compared to the previous version. In my opinion, it looked amazing, especially when compared to the older versions. It felt like the website was no longer just a simple page with links, but something that actually had structure, personality, and starting to go where I want it to be.

This was also around the time when I was still being a YouTuber, so I added YouTube channel statistics to the about me page. Looking back, it is kind of funny, but at the time, it made sense. I guess I really wanted the website to show what I was doing back then. It went from 37 commits to 199 commits, so yeah, many things were being worked in this version. It was probably one of the first times when the website really started to feel like a proper project instead of just a small experiment.

# Restyle - Version 3.0
Welcome to v3.0, which started being worked on around **June 1, 2024**.

At this point, I had spent quite some time learning new things. And then learning even more new things. And then learning even more new things. Web development seems endless. All of that eventually led to this version. This version was basically a restyle of the existing design. The overall structure was still familiar, but I wanted to make the website pop more and feel more alive. And the biggest part of that was animation.

For the animation, I used Framer Motion. It gave life to the existing design and made the website feel much smoother compared to before. Things could move, fade, slide, and do fancy little things that made the experience feel nicer. The gallery also got improved in this version. Images in the gallery could now be clicked to preview them in a bigger view, which made the portfolio pages feel more complete and easier to look through. The about me page was also adjusted, since apparently, I keep changing how I want to introduce myself on the internet.

But the most important focus of this version was maintainability.

Instead of keeping everything (the content data) inside a variable, I started using MDX to store the content for each portfolio and about page. This made the content much easier to edit, update, and add to. It felt like a much better approach compared to how things were handled before, especially if I wanted the website to keep growing in the future. And lastly, around this time, I also started wanting to add more things to the website. One of the ideas was to have my own blog, a place where I could share things, thoughts, or maybe random things for the internet.

Whether I will actually write anything or not is a different question, but hey, the idea is there.

# The migration - Version 4.0
By **April 26, 2025**, work had begun on what would become v4.0.

This one is going to be a short one. The main focus of this version was still maintainability, but this time more from the framework side of things.

Around this time, Next.js had become more and more popular. New major versions kept coming out here and there, and upgrading between each major version started to become quite painful for me. Especially when some things changed a lot, like the move and rework into the folder-based app structure for pages and routing.

Because of that, I started looking at other options. And honestly, part of the reason was simply curiosity. I wanted to try different frameworks and see how they approached things compared to Next.js, and to ease my pain on maintainability.

Remix was also starting to get more popular at the time. It became free to use, and after some time, it eventually became one with React Router. From what I understand, React Router v6 is basically like the v2 version of Remix. Or at least, something along that line. Since Next.js and Remix were both based on React, the migration process was actually not that bad. It was still work, of course, but it was much easier than rewriting everything from scratch.

In the end, it only took a couple of days.

Which, honestly, was pretty nice.

# What I wanted - Version 5.0
And finally, around **April 16, 2026**, work began on the current version of the website, v5.0.

At this point, it became clear to me that perhaps I didn’t choose the right framework for the job. Well, it was for learning’s sake, so I guess it was still worth it.

I learned a lot from hopping between frameworks, and the improvements were definitely there. From plain HTML, to Next.js, to Remix, and now finally to Astro. Since this website is mostly a content-focused website, Astro felt like a much better fit for what I actually needed. One thing that I really like about Astro is that it can support different types of UI frameworks. I still use React for certain components, since that is what I’m comfortable with, but if something can be done with plain Astro, then I will probably do that instead.

In this version, I also reworked and improved the whole design. The layout is still kind of the same, but with tweaks here and there to make it feel better and better. Welp, basically, what you see now is the result. Of course, some more tweaks might still be needed in the future. That is just how it goes.

# Final touches - Version 5.1.x
Blogs are finally available now! I can actually post content on my own website... finally! It's something I’ve wanted to do for a while. There is also a separate “Fun” blog for random stuff or other things. What kind of stuff will end up there? I honestly don’t know yet, but that's kind of the point.

There is also the table of contents to make navigating through longer posts a bit easier, along with a reading progress bar because... I kinda wanted one. I also added a global search component, which should make finding stuff across the website much easier.

Styling has also been cleaned up quite a bit, all the Markdown components are also properly styled now. Things like headings, lists, tables, code blocks, blockquotes, and a bunch of other stuff should hopefully look consistent with the rest of the website. For example, I can now do this:
```markdown title="Wow! A title"
# Hi, This is a codeblocks
```

And finally, there is now a proper SEO implementation. Hopefully... I don’t really know that much about SEO stuff yet, so... yea. <br /> `╮(￣ω￣;)╭`

And that’s it! At least, that is the history of this website until the current version. This page will be updated again if there are any big changes in the future.
